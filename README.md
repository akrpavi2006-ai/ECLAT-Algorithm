This project implements the **ECLAT (Equivalence Class Clustering and Bottom-Up Lattice Traversal)** algorithm to perform **Market Basket Analysis** on retail transaction data. The objective is to identify frequently purchased item combinations that can help businesses understand customer buying patterns.

Workflow
  1. Import required libraries.
  2. Load the transaction dataset.
  3. Initialize the ECLAT model.
  4. Set minimum support and combination lengths.
  5. Generate frequent itemsets.
  6. Store the results in a DataFrame.
  7. Sort the itemsets based on support.
  8. Display the top frequent item combinations.

Technologies Used
  - Python
  - Pandas
  - pyECLAT
  - Google Colab / Jupyter Notebook
